# 新酒馆设计宪章（v2）

新酒馆不是一套皮肤，而是**若干个各自完整的世界**，用户在设置里选择住进哪一个。每个世界有自己的材质、光线、字体、动作与记忆物件；它们之间**不共享外观**，只共享骨架（布局、信息结构、交互流程、可访问性）。把几个世界的元素缝在一起做出来的东西是四不像，是缺陷。

版本：v2（2026-09-14）。v1 的「暮雨里的玻璃灯屋」作废（它把六个方向缝成了一个）。

---

## 一、原则

1. **一个主题 = 一个世界**。它必须能被一句话描述成一个地方或一件物品，界面里每个元素都要能回答「你在这个世界里是什么、光从哪里照到你」。
2. **彻底**。选了「拟物」就要有真实的材质与光影，选了「简洁」就连阴影都不许有。做一半的世界比没有更糟。
3. **记忆点**。每个主题至少三件属于它自己的物件（发送键、消息的分隔方式、空状态插画……），让人一眼认出是它。
4. **骨架不变**。所有主题下，页面结构、组件位置、快捷键、文案完全一致；换主题只换世界，不换习惯。
5. **两种模式不是反色**。一个主题若同时提供明暗，两者是同一个世界的白天与夜晚，各自独立调色；一个主题也可以只有一种模式。
6. **禁忌是全局的**（见 §四），主题不能以「风格」为由违反。

## 二、主题引擎（工程契约）

### 2.1 结构

```
apps/web/src/
  themes/
    registry.ts              # ThemeMeta[]：id、名字、一句话、支持的模式、字体、预览色、插画组件
    slots.css                # 语义槽位清单与说明（只声明，不赋值；作为回退给一套「素」的值）
    materials.css            # 材质配方类：.surface-* .control .action-primary .edge-* …（用槽位变量实现，允许主题覆盖）
    <id>/theme.css           # 该主题全部槽位赋值（[data-theme=<id>][data-mode=light|dark]）+ 该主题的材质覆盖 + 纹理/动效
    <id>/theme.ts            # ThemeMeta
    <id>/illustrations.tsx   # 空状态等自绘插画（可选）
    <id>/signature.tsx       # 记忆物件的主题专属实现（发送键、swipe 指示、头像框、分隔）——通过 registry 注入
  components/ui/*            # 只用材质类与槽位，不写具体颜色/阴影/圆角
```

`<html data-theme="liuli" data-mode="light">`。`useUiStore` 存 `themeId` 与 `mode`（`light | dark | system`，主题不支持的模式自动回退到它支持的那个）。

### 2.2 语义槽位（组件唯一可用的变量）

```
表面    --canvas（最底层）--reading（阅读面）--panel（面板/侧栏）--control（输入/按钮底）--raised（弹层/抽屉）--overlay（遮罩）
边      --edge（分隔）--edge-strong --edge-focus（焦点）--edge-highlight（材质高光，可为 transparent）
文字    --ink --ink-2（次要）--ink-3（元信息）--ink-on-primary --ink-link --ink-quote（对白）--ink-action（动作/斜体）
强调    --accent --accent-soft --primary（主动作底）--primary-2（主动作渐变末端）--primary-edge --primary-glow
语义    --danger --success --warning --info
形      --r-panel --r-card --r-control --r-pill（数值由主题定，可为 0）
影      --shadow-panel --shadow-raised --shadow-control（可为 none）
字      --font-ui --font-story --font-display --font-mono；--story-size --story-leading --story-measure
动      --ease --dur-panel --dur-hover --dur-press；--motion-pulse（生成中的心跳动画名，可为 none）
纹理    --texture-canvas --texture-reading（`background-image`，可为 none）
```

材质类（`materials.css`）：`surface-reading` `surface-panel` `surface-control` `surface-raised` `edge-rule`（分隔线）`action-primary` `action-quiet`（次要按钮）`chip` `field`。它们用槽位实现默认形态；主题可用 `[data-theme=x] .action-primary { … }` 覆盖**形态**（浮雕、玻璃、扁平……），组件不知道差别。

记忆物件通过 `registry.ts` 的 `signature` 字段注入：`SendButton`、`SwipeIndicator`、`AvatarFrame`、`MessageDivider`、`EmptyIllustration(kind)`、`StreamingCursor`。主题没提供的用 `themes/_default` 的实现。

### 2.3 主题选择器

设置页「外观」：一排**活的预览卡**（每张卡里真实渲染一段消息 + 输入框 + 主按钮，用该主题的 `data-theme` 作用域），点选即切换，下方是模式切换（仅在该主题支持两种模式时出现）。不是下拉框。

### 2.4 字体

- 主题声明 `fonts.story / fonts.ui / fonts.display`，需要的 web 字体按主题懒加载（npm 分片包，`unicode-range`）。
- 首批可用：霞鹜文楷 屏幕版（`lxgw-wenkai-screen-webfont`）；Inter（`@fontsource-variable/inter`）；其余先用系统栈，M4 补。

### 2.5 验收

每个主题交付时必须附：桌面 1440 与手机 390、该主题支持的每种模式下的对话页、开始页、设置页、连接页截图；`scrollWidth === viewport`；一段 400 字中文故事文本的可读性截图；三件记忆物件的特写。由主会话逐张审。

## 三、六个世界

首发六个主题。每个都有自己的名字，不用形容词当名字。

### 3.1 琉璃 · Liuli（晶莹剔透）

**世界**：一间全由冰与琉璃砌成的亮室。光从四面来，穿过层层透明的板，在边缘折出细细的虹。没有实心的东西，一切都是透的、凉的、干净的。

- 模式：白琉璃（light，默认）/ 夜琉璃（dark）。
- 光与色：canvas 是极淡的冰蓝白 `oklch(0.985 0.006 220)`（夜：`oklch(0.20 0.03 230)`）；面板是多层透明板叠出的深度（`blur 24px`，底 `oklch(1 0 0 / 0.45)`；夜 `oklch(0.35 0.03 230 / 0.35)`），**边缘有 1px 的虹**（`conic-gradient` 极淡的青—紫—金，透明度 25%，只在边缘）；文字是冷墨 `oklch(0.28 0.02 240)`（夜 `oklch(0.93 0.01 230)`）；强调是冰青 `oklch(0.70 0.10 205)`。
- 主动作：一颗**切面水晶**——多边形（`clip-path` 八边形）、内部有折射渐变、悬停时虹边变亮、按下时透明度降低像被按进冰里。
- 字：界面 Inter；故事用清瘦的黑体（Noto Sans SC Light / PingFang Light），字重 300，行高 1.9——透亮感来自轻。
- 形：圆角 12 / 8 / 999；线 1px 高透明度白；影是**光**不是暗：`0 8px 30px oklch(0.7 0.05 220 / 0.25)`。
- 动：慢而滑（`cubic-bezier(.2,.8,.2,1)` 360ms）；生成中主按钮内部有缓慢流动的折射光（`background-position` 循环）。
- 记忆物件：切面水晶发送键；消息之间用一道细细的**光痕**分隔（1px 从透明到白到透明）；swipe 指示是一串小冰晶点（当前项是实心）；空状态插画：一块悬浮的冰棱与其中的气泡。
- 禁止：任何暖色（对白也用冰青而不是暖色）；实心按钮；纹理噪点。

### 3.2 书斋 · Shuzhai（古典优雅）

**世界**：一间旧书房。宣纸、墨、朱砂印、竹尺。文字是主角，装饰只有细细的双线与一枚印。慢、静、有分寸。

- 模式：宣纸（light，默认）/ 烛夜（dark）。
- 光与色：canvas 宣纸 `oklch(0.965 0.012 85)`（烛夜 `oklch(0.24 0.02 60)` 暖褐黑）；阅读面与 canvas 几乎同色，靠**双线框**（外粗内细，`oklch(0.45 0.03 70)`）与留白分隔；文字墨 `oklch(0.25 0.02 60)`；朱砂 `oklch(0.55 0.17 30)` 只用于印章、当前项与对白；次要文字用淡墨。
- 主动作：一枚**朱砂印**——方形、圆角 3px、朱砂底、白色篆体或图标、边缘有印泥的不匀（`box-shadow inset` 微噪）；按下像盖章：极短的下压与一圈淡红晕。
- 字：故事用宋体/明朝体（Noto Serif SC / Source Han Serif，系统回退 Songti SC / SimSun 视平台），17px，行高 2.0，`text-indent: 2em` 段首缩进，段间不留空；界面用同一宋体的小号或思源黑体细体；标题用楷（霞鹜文楷）。数字用旧式数字（`font-variant-numeric: oldstyle-nums`）。
- 形：圆角 0–3px；线是墨线；没有阴影，层级靠**纸的叠放**（上层纸略白、下层纸略暗，边缘一条 1px 暗线）。
- 动：几乎没有动画；面板出现是纸展开（只透明度，240ms）；生成中的光标是一支笔尖的竖线，不呼吸。
- 记忆物件：朱砂印发送键；消息用**回目式标题**分隔（居中的「· 第三回 ·」样式的细小分隔，或竖排的小签）；swipe 指示是右侧一枚竹签，上写「二／三」；用户头像是圆形墨戳，角色头像是方形印；空状态插画：一方砚台与一支笔。
- 禁止：玻璃、模糊、发光、彩色渐变；圆角大于 4px；无衬线的故事字。

### 3.3 素 · Su（现代简洁）

**世界**：一张白纸上的排版。没有材质，没有光影，只有黑、白、一根线和一个色。所有的美来自间距、对齐与字。

- 模式：白（light，默认）/ 黑（dark，`oklch(0.13 0 0)` 而非纯黑）。
- 光与色：canvas `oklch(0.99 0 0)`；面板与 canvas 同色，靠 1px `oklch(0.88 0 0)` 的线分隔；文字 `oklch(0.15 0 0)`，次要 `oklch(0.50 0 0)`；唯一的色是**国际橙** `oklch(0.68 0.20 40)`（黑模式同色）——只用于主动作、当前项、对白。
- 主动作：一个**黑色圆点**（黑模式为白）——直径 36px 的实心圆，无渐变无阴影；悬停变橙；按下缩 4%（这是全宪章唯一允许的缩放）。
- 字：Inter（`@fontsource-variable/inter`）+ 思源黑体；故事 16px 行高 1.8；标题用大号细体（28px/300）；数字 tabular；字距紧（`-0.01em`）。
- 形：圆角 6 / 4 / 999；线只有 1px；阴影 none；边框只在必要处。
- 动：120ms 线性或 `ease-out`，只做透明度；无滑入，无呼吸；流式光标是 2px 宽的实心块，固定不闪。
- 记忆物件：黑圆点发送键；消息之间**没有分隔物**，只有 32px 的留白和左侧对齐的时间戳（tabular、极小）；swipe 指示是「2 / 3」纯文字 + 两个极简箭头；空状态插画：没有插画，只有一行大字。
- 禁止：任何材质、纹理、模糊、渐变、阴影、圆角超过 6px、第二种色、装饰性图标。

### 3.4 酒馆 · Jiuguan（拟物逼真）

**世界**：一间真的酒馆。橡木桌面、皮革包边的账本、黄铜灯与铆钉、羊皮纸、蜡封。东西有重量，光有方向，按钮按下去会陷进去。

- 模式：白日（light）/ 夜灯（dark，默认）。两者是同一间屋子的不同时刻：白日光从窗来，冷白、影长；夜灯光从桌上的灯来，暖黄、影短。
- 材质（必须真实，用 CSS 渐变 + SVG 纹理，不用位图照片）：橡木（canvas，`repeating-linear-gradient` 木纹 + 噪点，深棕 `oklch(0.32 0.04 55)`）；羊皮纸（阅读面，`oklch(0.90 0.03 80)`，边缘有烧灼渐变与轻微不规则 `border-radius`）；皮革（面板，`oklch(0.30 0.04 40)`，细密颗粒纹理，四周**缝线**用 `dashed` 的 1px 浅线）；黄铜（主动作与铆钉，竖向渐变 + 高光 + 深边 + 外投影）。
- 主动作：**黄铜按钮**——圆形，浮雕（顶部高光、底部暗边、外投影 `0 3px 0 深铜 + 0 6px 12px 影`），按下时 `translateY(3px)` 且外投影消失（真的被按进去）。生成中灯芯发光。
- 字：故事用霞鹜文楷 17px 行高 1.9 写在羊皮纸上，墨色略带棕；界面用衬线小号（Noto Serif SC）像账本手写；标题用楷。
- 形：圆角 10 / 6 / 999；所有边都有厚度（1px 亮 + 1px 暗）；阴影有方向（白日向右下长影，夜灯短而暖）。
- 动：物理的：按压 100ms、回弹无；面板像翻开账本（`rotateY` 极小角度 + 透明度）；生成中黄铜灯呼吸发光。
- 记忆物件：黄铜灯发送键；消息是**一张张羊皮纸条**用黄铜铆钉钉在皮革上（每条消息左上角一颗 6px 铆钉）；swipe 指示是一枚**蜡封**（圆形、深红、上有数字）；头像是嵌在铜框里的圆形肖像；空状态插画：一盏灯与一杯酒（单线但带阴影）。
- 禁止：扁平；无方向的阴影；玻璃模糊；冷色调（除白日的窗光）。

### 3.5 雨夜 · Yuye（忧郁蓝调）

**世界**：深夜的窗前，雨在玻璃上流，远处有一点暖黄的灯。一切是蓝的、湿的、安静的，带着颗粒，像一部慢电影。

- 模式：只有夜（dark）。
- 光与色：canvas 是深海蓝 `oklch(0.19 0.045 258)` 到 `oklch(0.24 0.05 250)` 的大面积渐变，叠 2.5% 的胶片颗粒与**雨**（`repeating-linear-gradient` 115° 极淡斜线，40s 缓慢下移；`prefers-reduced-motion` 静止；设置可关）；阅读面 `oklch(0.25 0.035 255)` 无边框，靠明度分开；面板是**湿玻璃**（`blur 18px`，底 `oklch(0.28 0.04 255 / 0.5)`，上缘 1px 高光，偶有一两滴「水珠」高光点）；文字 `oklch(0.88 0.02 245)`，次要 `oklch(0.66 0.03 248)`；唯一暖色是远处的灯 `oklch(0.82 0.10 75)`——用于主动作、对白、当前项。
- 主动作：**远处的一盏灯**——圆形、暗铜底、中心一点暖光（径向渐变），悬停时光晕扩大，生成中呼吸。
- 字：故事用霞鹜文楷 16px 行高 1.95，颜色略偏蓝白；界面用思源黑体；时间戳用等宽小号。
- 形：圆角 12 / 8 / 999；线几乎不用；层级靠明度与模糊。
- 动：慢（400ms）、软、只有透明度与极小位移；雨常在；生成中灯呼吸。
- 记忆物件：远灯发送键；背景的雨；消息之间用**水痕**分隔（一道从左侧淡入淡出的 1px 蓝白线）；swipe 指示是右侧一组小水珠；空状态插画：雨窗与窗台上的一杯热饮。
- 禁止：白色大面积；饱和色；霓虹；任何超过一个的暖色；无颗粒的纯净渐变。

### 3.6 暖房 · Nuanfang（可爱治愈）

**世界**：一间午后的温室。奶油色的墙、圆滚滚的家具、软软的布，桌上有一只马克杯，窗台有小盆栽。一切都是圆的、软的、暖的，让人想把脸埋进去。

- 模式：只有白天（light）。
- 光与色：canvas 奶油 `oklch(0.97 0.02 85)`；阅读面是更白的奶油 `oklch(0.99 0.01 90)`，圆角大、有柔和的**软影**（`0 6px 20px oklch(0.6 0.08 60 / 0.18)`）；面板是薄荷奶昔 `oklch(0.95 0.03 165)` 或杏子 `oklch(0.95 0.04 55)`（按用途固定，不随机）；文字是软褐 `oklch(0.35 0.04 50)`；强调是草莓 `oklch(0.72 0.14 15)`，第二色薄荷 `oklch(0.70 0.10 165)`——对白用草莓。
- 主动作：一颗**软糖按钮**——胶囊形、渐变（杏子 → 草莓）、顶部一条高光像糖衣、按下时轻轻压扁（`scaleY(.94)`，允许的例外）。
- 字：故事用霞鹜文楷 16.5px 行高 1.95；界面用圆体（系统 `Yuanti SC` / `YouYuan`；无则思源黑体）+ 略大的字号 14px；标题用楷体带一点字距。
- 形：圆角 20 / 14 / 999（这是唯一允许大圆角的世界）；线不用，靠色块与软影；所有图标线宽 2px 圆头。
- 动：轻柔的弹性（`cubic-bezier(.34,1.3,.64,1)` 260ms，唯一允许弹性的世界，但幅度小）；生成中主按钮像呼吸的小动物轻轻起伏。
- 记忆物件：软糖发送键；消息是**一张张便签**，角色消息带一枚小小的手绘贴纸（星星、叶子、杯子，`currentColor` 单线，随机但对该消息固定）；swipe 指示是一串小豆子；头像是圆形带 3px 奶油描边像贴纸；空状态插画：马克杯里冒着热气的小猫。
- 禁止：黑色；锐角；细线；冷灰；任何「高级感」的克制——这个世界就是要甜。

## 四、全局禁忌（任何主题出现即为缺陷）

- shadcn / Tailwind 默认模样的按钮与卡片；灰底叠灰卡叠灰边。
- 紫/蓝/粉「AI」渐变、光斑、网格背景、星星图标。
- emoji 当图标；库存图标放大当插画。
- 产品手册语气的说明文字（「点击此处以…」）。
- 一个主题里出现另一个主题的材质（雨夜里的朱砂印、素里的木纹）。
- 主题只换颜色不换形态、字体与记忆物件。

## 五、实施顺序

1. **引擎**：槽位契约、材质类、`registry`、`data-theme/data-mode` 切换、选择器预览卡、记忆物件注入点；把现有组件全部改为只用槽位与材质类（这一步完成时应用外观是「素」的默认形态）。
